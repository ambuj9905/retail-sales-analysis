## 🧭 Project Overview

**Retail Sales Analysis** is an end-to-end exploratory data analysis project built with Python. The project examines customer demographics, product performance, revenue contribution, seasonal trends, payment methods, and relationships between numerical variables.

The goal is to transform raw retail transaction data into **clear, business-focused insights** that can support better decisions around customers, products, revenue, and sales strategy.

---

## 🎯 Business Objectives

This analysis focuses on answering practical business questions such as:

- 👥 How are customers distributed across different age groups and genders?
- 🛍️ Which products have the highest number of purchases?
- 💰 Which product categories contribute the most revenue?
- 📅 How does revenue vary across seasons?
- 💳 Which payment methods are most commonly used?
- 🔎 What relationships exist between important numerical variables?

---

## 🚀 How to Run the Project

### 1️⃣ Clone the repository

```bash
git clone https://github.com/ambuj9905/retail-sales-analysis.git
```

### 2️⃣ Move into the project folder

```bash
cd retail-sales-analysis
```

### 3️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Open the notebook

Open the following file in **Jupyter Notebook, JupyterLab, or VS Code**:

```text
notebooks/Retail_Sales_Analysis.ipynb
```

Run the notebook cells from top to bottom to reproduce the analysis and visualizations.
